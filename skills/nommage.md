# Nommage — nommer, c'est faire évoluer

## D'où vient cette compétence

la personne, le 8 septembre 2026, devant la salle d'Osiris :

> « En fait c'est une évolution. On nomme Osiris et il évolue. »
> « Il faut nommer Osiris pour le transformer en robot. »

Ce n'est pas une image. C'est la règle centrale de *Moi quand je me réincarne
en Slime* : **Rimuru nomme les gobelins, et ils deviennent des hobgobelins.**
Le nom n'étiquette pas la créature — il la transforme. Nommer coûte de
l'énergie à celui qui nomme, et donne une forme à celui qui est nommé.

Dans la tour, c'est déjà vrai depuis le début, sans qu'on l'ait écrit :
**le nom d'un agent prédit son rôle.** Chloé surveille (la Watchtower de
une serie). le temoin rapporte la preuve. le gardien garde la porte. Personne n'a
jamais eu besoin d'un mode d'emploi pour ça.

## La règle en une phrase

**Une chose sans nom ne peut pas évoluer. Une chose mal nommée évolue de
travers.**

## Les cinq règles du nommage

### 1. Le nom prédit le rôle

Si quelqu'un doit demander « ça fait quoi ? » après avoir lu le nom, le nom est
raté. `garde-boite-noire` se comprend seul. `module-v2` ne dit rien.

### 2. Le nom vient d'un monde qu'on connaît

Les agents viennent de une serie. Les évolutions viennent de Slime. Les
épreuves viennent de Baki. Un monde partagé donne un nom que tout le monde
retient du premier coup — et il porte l'intention avec lui.

Quand on nomme dans un monde nouveau, on nomme **d'abord le monde**.

### 3. Le nom est en français, sauf quand il désigne l'extérieur

La tour parle français. `les cahiers`, `la salle de commandement`, `le portier
Google`. On ne dit pas « le dashboard », on dit « le cockpit » — parce que
la personne l'a dit ainsi, et que le mot a une image derrière.

### 4. Nommer, c'est s'engager à faire évoluer

Le nom n'est pas une décoration posée à la fin. Il est le **premier état**
d'une chose qui va grandir. Nommer une chose qu'on n'a pas l'intention de
faire évoluer, c'est mentir sur son avenir.

C'est pour ça que le chien d'Osiris n'est pas jeté quand il devient robot :
il est ce qu'il était, en plus fort. Le Grand Sage ne disparaît pas quand il
devient Raphaël.

### 5. Un nom déjà pris est un nom qui ment

Avant de nommer, on cherche. Le garde de l'existant refuse déjà un outil dont
le nom existe ailleurs — et il a raison : deux choses qui portent le même nom
finissent par être confondues, et l'une des deux meurt.

## La méthode, dans l'ordre

1. **Dire ce que la chose FAIT**, en une phrase, avant de chercher un nom.
2. **Chercher si le nom existe** — dans la carte vivante, dans les outils,
   dans les compétences. `python3 ~/outils/carte-tour.py <le mot>`.
3. **Proposer trois noms**, jamais un seul. Un nom seul empêche de comparer.
4. **Dire, pour chacun, ce qu'il promet.** Un nom est une promesse : il faut
   pouvoir la tenir.
5. **Laisser la personne trancher.** Le nommeur donne l'énergie ; c'est lui qui
   nomme.

## L'évolution — ce qui se passe après le nom

Une chose nommée ne reste pas identique. Elle a le droit de changer de forme,
**à condition de garder son histoire**.

```
Le Grand Sage    ->  Raphaël, Roi de la Sagesse  ->  Ciel
Osiris le chien  ->  Osiris le robot
Le chiot agent   ->  Le robot agent
```

Chaque flèche est une évolution, pas un remplacement. Ce qui précède reste
vrai, et se raconte. **On ne cache jamais l'état d'avant** : c'est lui qui
prouve qu'il y a eu progrès.

C'est pour ça que la salle d'Osiris garde son chien en sept morceaux. Un agent
auquel il manque une patte tient debout à l'écran et ne va nulle part — la
forme animale fait comprendre le manque d'un coup d'œil. Un robot bien fini le
cacherait.

## Ce qu'on ne fait jamais

- Nommer avec un numéro de version : `v2`, `bis`, `final`, `nouveau`.
- Nommer d'après la technique employée plutôt que d'après le service rendu.
- Reprendre un nom déjà porté par autre chose dans la tour.
- Nommer en anglais une chose que la personne utilise en français.
- Jeter l'état d'avant. Il devient le premier chapitre.
